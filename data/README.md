# Data Set 
The data set within this data directory contains the csv for testing the program with only movies that were released in 2024 nomintaed for the big 5 award categpries
To replicate, download full data set from https://www.kaggle.com/datasets/unanimad/the-oscar-award?resource=download and filter year and award. 

Running this data set, expect to see movies that have a cast and crew of the most successful candidates at the 2024 oscar awards.
